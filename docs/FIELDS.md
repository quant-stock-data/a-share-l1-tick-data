## 三个容易误读的地方

1. **累积量额不是本帧成交量额。** 两帧之差可以表示统计区间内的增量（要先处理复位与交易阶段），但不应把这种差值误当逐笔成交明细。
2. **档位价为 0 不等于真实 0 元挂单。** 集合竞价、特殊证券状态等阶段可能有零值/空档，应根据市场规则区分。
3. **通常约 3 秒，不保证连续无缺口。** 本样本相邻间隔 4,742 次为 3 秒，完整交易日仍包含 9、15 秒及午间等较长间隔。
